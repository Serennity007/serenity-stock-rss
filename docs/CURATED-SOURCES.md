# 乔木精选本地筛选

通过命令面板的「筛选乔木精选」、阅读器工具栏的漏斗按钮，或设置 → 来源 →「筛选乔木精选」打开选择窗口。窗口读取 `/api/sources` 的完整目录；请求失败时使用本地目录。不把当前用户的名单写回服务器。

每个源只属于一个分类：微信公众号、播客、Newsletter、博客与资讯。分组顺序固定，同类按名称排序；「全部」是总览，频道可见性和服务器关闭状态只作为行内标记。可以搜索、全选或清空当前所列的源。

第一次打开时全选。保存后的 `settings.pickedSourceIds` 独立于服务器的 `sources[].enabled`，刷新目录不会覆盖选择。`null` 表示恢复默认精选规则，`[]` 表示明确不选任何精选源。之前选中的源即使暂时不在目录中，也保留其 ID。

保存后，精选频道菜单、聚合列表和缓存频道应用同一份选择。隐藏或服务器关闭的源也可以选择；本地选择不能让服务器恢复抓取。个人 RSS、库内笔记和已关注的播客保持独立，已有收藏及保存的文章不删除。

选择不超过 36 个源时，全部精选按源读取最近 12 篇，最多 8 个请求同时执行；该模式没有更早分页。更大的名单过滤聚合接口返回的每一页，继续保留服务器的分页游标，因此可以继续加载更早文章。恢复默认规则后，重新刷新以获取此前排除的文章。

运行 `npm run check` 验证静态检查、测试、类型检查与构建。`tests/curated-sources.test.ts` 覆盖筛选规则和持久化；`tests/curated-source-picker.test.ts` 在 DOM 中验证分组、批量选择、保存、恢复和离线回退。
